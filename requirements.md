# MWALIMU RULE BASED INTELLIGENCE SYSTEM
## Functional Requirements
1. FROO1. The system should allow students to register or login the system.
2. FR002. The system should allow students to update their proile.
3. FR003. The system should allow students to choose their subject of choice.
4. FR004. The system should allow students to attempt various activities based on the subject they choose.
5. FR005. The system should allow be able to generate tasks.
6. FR006. The system should be able  to adapt and learn.
7. FR007. The system should allow teachers and parents to view and tracks students' progress.

## Non-Functional requirements
1. NFR001. The system should respond within 2-5 seconds.
2. NFR002. The system should be able to accomodate a maximum of 500 students without crashing.
3. NFR003. The system should be able easy to use and appealing to learners.
4. NFR004. The system should have daily streak reminders.
5. NFR005. The system should generate badges and leadersboard for learners.

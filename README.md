# MWALIMU: Rule-Based Intelligent Learning System

## Overview

MWALIMU is a Python-based educational learning system designed to support learners through subject-based learning activities, assessments, performance evaluation, and rule-based learning recommendations.

The project explores how predefined rules can be used to adapt learning activities according to a learner's performance.

## Objectives

- Provide structured learning activities for junior learners.
- Support Mathematics, English, and Kiswahili learning.
- Assess learner performance using defined criteria.
- Use rule-based logic to recommend suitable learning activities.
- Store questions, rules, and learner records using JSON files.

## Features

- Learner registration and selection.
- Subject selection and learning activities.
- Performance assessment.
- Rule-based performance classification.
- Adaptive learning recommendations.
- JSON-based data storage.


## Technologies Used

- Python
- JSON
- VS Code
- Git and GitHub

## Project Structure

The project contains Python modules for learner management, subject activities, validation, assessment, adaptive recommendations, and storage, alongside JSON files for questions and performance rules.

## Getting Started

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the main program:

   `python Main.py`

Ensure that the required JSON files are present in the expected locations before running the program.
